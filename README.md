# Thai Pollution Atlas — แผนที่มลพิษไทย (รุ่นชุมชน)

เว็บไซต์ข้อมูลสาธารณะสำหรับดูหลักฐานด้านคุณภาพสิ่งแวดล้อมในไทย แยกตามจังหวัด พร้อมลิงก์ต้นทาง ช่วงเวลา และข้อจำกัดของหลักฐาน

**อ่านก่อนแชร์:** มี *ทะเบียนจังหวัดครบ 77 จังหวัด* ไม่ใช่ *ผลตรวจครอบคลุมทั้ง 77 จังหวัด* สีเทา = ยังไม่มีข้อมูลที่บันทึกในชั้นที่เลือก **ไม่ใช่ปลอดภัย** และสีแดงสะท้อนผลตรวจ/รายงาน *ในอดีต* ไม่ใช่สภาพแวดล้อมปัจจุบัน

## ความครอบคลุมข้อมูล ณ 21 พ.ย. 2569

| ชั้นข้อมูล | ความครอบคลุม | วิธีอ่าน |
|---|---|---|
| ทะเบียนจังหวัด | 77/77 | ชื่อ รหัส และแผนที่ **ไม่ใช่ตัวชี้วัดมลพิษ** |
| ฝุ่น PM2.5 ย้อนหลังปี 2568 | 57 จังหวัด | อยู่ในรายชื่อจังหวัดที่เคยมีระดับสีแดง (>75.1 µg/m³) จาก **รายงานราชการเดียว**; 20 จังหวัดที่เหลือไม่ได้แปลว่าไม่มีฝุ่น |
| น้ำ/กากอุตสาหกรรม | 12 บันทึก ครอบคลุม 10 จังหวัด | กรณีศึกษาบางพื้นที่ที่มีแหล่งอ้างอิง ไม่ใช่ census หรือการตรวจครบทุกพื้นที่ |
| รวมจังหวัดที่มีรายการอย่างน้อยหนึ่งชั้น | 61/77 | ทั้งข้อมูลอากาศและคุณภาพน้ำ **ห้ามนำมารวมเป็นคะแนนความเสี่ยงเดียว** |

### ชั้นน้ำ/กากอุตสาหกรรม

- `exceeded`: ข่าวหรือรายงานระบุค่าวัดเกินเกณฑ์ **เฉพาะจุด/วันที่**
- `watch`: อยู่ในระบบเฝ้าระวังหรือมีแหล่งข้อมูลวัด แต่ไม่สรุปว่าเกินเกณฑ์
- `reported`: มีรายงานเหตุการณ์/ข้อร้องเรียน; ผลตรวจยืนยันอาจยังไม่มี
- `unknown`: ไม่มีรายการกรณีศึกษาในชุดนี้ (ไม่ใช่ปลอดภัย)

### ชั้นฝุ่น PM2.5 ปี 2568

- `exceeded`: อยู่ในรายชื่อ 57 จังหวัดที่รายงานกรมอนามัยระบุว่าเคยมี PM2.5 ถึงระดับมีผลกระทบต่อสุขภาพ (สีแดง **มากกว่า 75.1 µg/m³**) ในรอบเฝ้าระวังปี 2568
- `unknown`: ไม่อยู่ในรายชื่อ **ไม่ใช่หลักฐานว่าผ่านเกณฑ์**
- รายงานไม่ได้แจกค่าฝุ่นรายวัน/รายสถานีให้แต่ละจังหวัดในข้อความที่นำมาใช้ในชุดนี้ ไม่มีการคาดเดาค่าเหล่านั้น

## ข้อมูลต้นทางและวิธีการ

1. **กรมอนามัย** รายงานเฝ้าระวังด้านอนามัยสิ่งแวดล้อมปี 2569 สรุป PM2.5 ปี 2568 แผนภูมิที่ 147: [PDF ของหน่วยงาน](https://planning.anamai.moph.go.th/web-upload/20xa4d80079fdd38ace9fb48a050e5b52e4/202606/m_magazine/37317/5716/file_download/9d337b211c7edd99e403709150ddcad2.pdf) — แยกเป็น 57 records ทางเทคนิค แต่ **เป็นหลักฐานจากรายงานเดียว**
2. **กรมควบคุมมลพิษ** [IWIS](https://iwis.pcd.go.th/dashboard) และ [ข้อมูลคุณภาพน้ำ](https://pcdweb.pcd.go.th/water-quality/data) — โปรดตรวจ timestamp ของแต่ละสถานี (ข้อมูลเว็บนี้ไม่ดึงค่าปัจจุบันอัตโนมัติ)
3. **กรุงเทพมหานคร** [ข้อมูลคุณภาพน้ำในคลองและแม่น้ำเจ้าพระยา](https://data.go.th/th/dataset/waterquality) — ตาราง BOD, DO, NH3 และพิกัดจุดตรวจ; ยังไม่ลงสรุปค่าเกินเกณฑ์โดยไม่มีค่าตรวจเฉพาะจุด
4. **Thai PBS The Active** [สำรวจแผ่นดินเปื้อนพิษ](https://theactive.thaipbs.or.th/data/toxic-land) — กรณีศึกษาและสรุปผลตรวจจากหน่วยงานรัฐ ข้อกล่าวหา/ข้อโต้แย้งต้องแยกจากผลวิเคราะห์ที่พิสูจน์แล้ว
5. **GeoThai** [ขอบเขต 77 จังหวัด](https://github.com/GeoThai/boundaries) — ใช้เฉพาะสำหรับรูปทรงและชื่อ/รหัสจังหวัด
6. **Air4Thai** [เช็กค่าฝุ่นปัจจุบัน](https://www.air4thai.com/) — เครื่องมือภายนอก ไม่ได้ฝังค่าที่อาจล้าสมัย

`data/incidents.json` บันทึก `layer`, `province_code`, `headline`, `area`, `substance`, `sample_date`, `report_date`, `finding`, `limitation`, `source_name`, `source_url` สำหรับแต่ละรายการ พร้อม `provinces` เป็นสารบบ 77 จังหวัดและลิงก์หน่วยงานกลางที่ผู้ใช้สามารถตรวจเพิ่มเองได้ ไม่ได้แปลว่าทุกจังหวัดมีสถานีตรวจ

**สิ่งที่ยังขาด:** ผลตรวจสารหนู/ปรอท/ตะกั่ว/แคดเมียมรายจุดจากระบบราชการที่ดาวน์โหลดได้ครบทุกจังหวัดและครบทุกรอบ, สถานการณ์สด PM2.5, พิกัดการตรวจทั้งหมด, ข้อมูลน้ำบาดาล/ประปา/ดิน/อาหารแยกประเภท และการทวนสอบเชิงบรรณาธิการก่อนทุกการอัปเดต ต้องไม่อ้างว่าเว็บนี้มีข้อมูลครบเหล่านี้

## วิธีแก้ข้อมูลและส่งหลักฐาน

เปิด [GitHub Issue](https://github.com/thanakritdacontact-tech/thailand-pollution-atlas/issues/new) พร้อมระบุชื่อจังหวัด **พื้นที่จุดตรวจ**, สารและหน่วยวัด, วันเก็บตัวอย่าง, ค่าที่ตรวจ, มาตรฐานเทียบเคียง, ลิงก์หน่วยงานที่ตรวจ และวันประกาศผล ห้ามยกระดับเพียงข้อร้องเรียนหรือบทความที่ไร้ผลตรวจเป็น `exceeded`

## การพัฒนาและ deploy

Static site; ไม่มี backend หรือ tracking และไม่ใช้ API key. ต้องมีอินเทอร์เน็ตโหลด GeoJSON จาก GeoThai และชุดข้อมูลจากโฟลเดอร์ `/data/`. ตั้ง GitHub Pages Source = GitHub Actions; workflow `.github/workflows/deploy.yml` จะทำงานเมื่อ Push `main`.

```bash
python3 tests/validate_data.py
node --check assets/app.js
```

ข้อมูลใช้เพื่อการศึกษาและตรวจสอบเบื้องต้น ไม่ใช้แทนประกาศเตือนภัยหรือคำแนะนำเจ้าหน้าที่ และไม่ควรอ้างเป็นค่าตรวจปัจจุบัน
